YUS STORE — WEBSITE TOKO PRODUK DIGITAL

Isi folder:
- index.html : halaman login, katalog, keranjang, pembayaran, dan checkout
- style.css  : desain responsive dengan efek liquid glass
- app.js     : katalog produk, login/registrasi lokal, keranjang, upload bukti, dan konfirmasi WhatsApp

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka index.html di browser.
3. Daftar akun baru, lalu login.
4. Tambahkan produk ke keranjang, pilih metode pembayaran, pilih gambar bukti transfer, lalu klik konfirmasi.
5. WhatsApp akan terbuka dengan detail pesanan. Lampirkan gambar bukti transfer secara manual.

CATATAN PENTING
- Ini versi frontend HTML/CSS/JS tanpa database/backend. Akun disimpan di localStorage browser dan kata sandi tidak aman untuk produksi. Gunakan hanya untuk demo/prototipe; jangan gunakan kata sandi penting.
- Karena tidak ada server, login bisa dilewati oleh orang yang mengubah kode/browser dan data tidak tersinkron antarperangkat.
- Tautan wa.me tidak bisa menyisipkan file bukti transfer secara otomatis. Website memasukkan nama file ke pesan dan meminta pengguna melampirkan gambar manual.
- Pastikan Anda berhak menjual/menawarkan setiap akun atau layanan digital yang terdaftar dan ikuti ketentuan layanan masing-masing penyedia.
- Harga produk dapat diedit pada array `products` di app.js.
